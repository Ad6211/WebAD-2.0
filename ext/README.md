# Mimo, le petit compagnon

Mimo est une extension WebAD de type compagnon de page, inspirée du principe
Shimeji et dessinée spécialement pour WebAD. Il se promène dans la fenêtre,
rebondit doucement, cligne des yeux, réagit au clic et peut être déplacé par
glisser-déposer. Les boutons visibles au survol permettent de le mettre en
pause ou de le cacher sur la page courante.

## Installation

1. Ouvrez `webad:extensions` dans WebAD.
2. Choisissez **Installer depuis un dossier…** et faites confiance au script.
3. Sélectionnez ce dossier `ext`.
4. Activez l’extension si besoin, puis rechargez la page HTTP ou HTTPS.

Mimo est un compagnon affiché dans la page Web : il ne se déplace pas sur le
bureau ni sur les autres fenêtres. Il n’utilise aucune image, police ou
bibliothèque distante, ne collecte pas de données et ne s’exécute pas en
navigation privée. Le bouton × le retire jusqu’au prochain chargement.
